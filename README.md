## 🎯 Objetivo
Manipular archivos mediante los métodos y clases que proporciona Java (`File`, `Scanner`, `FileReader`, `BufferedReader`, `FileWriter`, `BufferedWriter`).

## 📚 Ejercicios

### Primera parte: lectura de archivos
| N° | Ejercicio | Archivo | Clases / concepto |
|----|-----------|---------|-------------------|
| 1 | Agencia de detectives | `pistas.txt` | Scanner, línea por línea, contador |
| 2 | Estación espacial | `mensaje.txt` | FileReader + `read()` |
| 3 | Museo digital | `obras.txt` | Nombre + categoría, clasificación |
| 4 | Parque de aventuras | `resultados.txt` | BufferedReader, total y máximo |

### Segunda parte: escritura y procesamiento
| N° | Ejercicio | Archivo | Clases / concepto |
|----|-----------|---------|-------------------|
| 5 | Biblioteca inteligente | `libros.txt` | Registrar, buscar, contar, validar existencia |
| 6 | Mensajes secretos | `secreto.txt` | FileWriter + BufferedWriter, modo append |
| 7 | Competencia de videojuegos | `jugadores.txt` | Promedio, máximo, filtro > 70, validación |
| 8 | Control de temperatura | `temperaturas.txt` | Promedio, máxima, > 30 °C, excepciones |
| 9 | Diario de exploradores | `descubrimientos.txt` | Append, búsqueda, validar archivo |
| 10 | Ventas de una cafetería | `ventas.txt` | BufferedWriter, total, producto más caro |

## ▶️ Cómo ejecutar
```bash
cd src
javac *.java
java Ejercicio1
```

## 🌿 Trabajo colaborativo
Cada integrante trabaja en su propia rama (`rama-nombre`) con uno o dos ejercicios y luego se hace *merge* a `main`.
